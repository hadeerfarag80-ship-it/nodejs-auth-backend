# 📚 Node.js Auth Backend API

مشروع **Backend API** مبني بـ **Node.js** و **Express.js** مع **MongoDB** لإدارة البيانات بشكل آمن.  
يوفر هذا المشروع نظام **تسجيل مستخدمين**، **تسجيل دخول باستخدام JWT**، حماية المسارات حسب صلاحيات المستخدم (**Admin/User**) بالإضافة إلى إدارة **الكتب والمؤلفين**.

---

## ✨ المميزات

- ✅ تسجيل مستخدمين (Register) وتسجيل الدخول (Login) باستخدام **JWT**  
- ✅ حماية المسارات باستخدام **Middleware** للتحقق من التوكن وصلاحيات المستخدم  
- ✅ **CRUD للمستخدمين**: إنشاء، قراءة، تعديل، حذف  
- ✅ **CRUD للكتب والمؤلفين**  
- ✅ تشفير كلمات السر باستخدام **bcrypt**  
- ✅ إدارة الصلاحيات: **Admin/User**  
- ✅ التحقق من صحة البيانات باستخدام **Joi**

---

## 📂 مسارات API

### المستخدمين (Users)

| العملية | المسار | الصلاحية |
|---------|--------|-----------|
| تسجيل مستخدم جديد | `POST /api/auth/register` | الجميع |
| تسجيل دخول | `POST /api/auth/login` | الجميع |
| جلب كل المستخدمين | `GET /api/users` | Admin فقط |
| جلب مستخدم محدد | `GET /api/users/:id` | Admin أو صاحب الحساب |
| تعديل مستخدم | `PUT /api/users/:id` | Admin أو صاحب الحساب |
| حذف مستخدم | `DELETE /api/users/:id` | Admin أو صاحب الحساب |

### الكتب (Books)

| العملية | المسار | الصلاحية |
|---------|--------|-----------|
| جلب كل الكتب | `GET /api/books` | الجميع |
| إضافة كتاب جديد | `POST /api/books` | Admin فقط |
| تعديل كتاب | `PUT /api/books/:id` | Admin فقط |
| حذف كتاب | `DELETE /api/books/:id` | Admin فقط |

### المؤلفين (Authors)

| العملية | المسار | الصلاحية |
|---------|--------|-----------|
| جلب كل المؤلفين | `GET /api/authors` | الجميع |
| إضافة مؤلف | `POST /api/authors` | Admin فقط |
| تعديل مؤلف | `PUT /api/authors/:id` | Admin فقط |
| حذف مؤلف | `DELETE /api/authors/:id` | Admin فقط |
