# Book Store API

مشروع Node.js لإدارة مكتبة كتب.

## الأدوات المستخدمة
- Node.js
- Express.js
- JavaScript

## وصف المشروع
هذا المشروع هو API (واجهة برمجية) لإدارة الكتب والمؤلفين في مكتبة.  
يمكنك من:
- إضافة وتعديل وحذف الكتب
- إضافة وتعديل وحذف المؤلفين
- عرض بيانات الكتب والمؤلفين

## كيفية التشغيل
1. انسخي المشروع على جهازك:
   git clone https://github.com/username/book-store.api.git
2. افتحي المشروع:
   cd book-store.api
3. ثبتي الحزم المطلوبة:
   npm install
4. شغلي المشروع:
   node app.js
5. التطبيق سيعمل على الرابط:
   http://localhost:3000
